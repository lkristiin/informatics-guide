# Справочник: Информатика для первокурсника

## Цель
Создание мини-справочника с базовыми понятиями по информатике для помощи первокурсникам.

## Автор
Криcтина Моренкова

## Выбранная тема
Системы счисления

## Список файлов
- README.md - описание проекта
- glossary.md - словарь терминов
- examples.md - примеры задач
- sources.md - источники литературы

## Инструкция чтения
Начните с изучения файла glossary.md, чтобы освоить основные определения. Затем перейдите к examples.md для закрепления материала на практике. Список использованной литературы находится в sources.md.
