# Вопросы для самопроверки

**Вопрос 1:** Что такое основание системы счисления?
**Ответ:** Это количество различных цифр, используемых для записи чисел в данной системе.

**Вопрос 2:** Какие цифры используются в двоичной системе?
**Ответ:** Только 0 и 1.

**Вопрос 3:** Сколько бит в одном байте?
**Ответ:** В одном байте 8 бит.
