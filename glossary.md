# Словарь терминов
- **Система счисления** - знаковая система, в которой числа записываются по определенным правилам с помощью символов (цифр).
- **Основание системы счисления** - количество различных цифр, используемых для записи чисел в данной системе.
- **Двоичная система** - позиционная система счисления с основанием 2, использующая цифры 0 и 1.
- **Десятичная система** - позиционная система счисления с основанием 10, привычная для человека.
- **Бит** - минимальная единица измерения информации, принимающая значение 0 или 1.
- **Байт** - единица измерения количества информации, равная 8 битам.
- **Позиционная система** - система, где значение цифры зависит от ее позиции (разряда) в числе.
- **Шестнадцатиричная система** - система счисления с основанием 16, использующая цифры от 0 до 9 и латинские буквы A-F.
